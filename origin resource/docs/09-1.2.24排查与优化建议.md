后续体验建议：

1. 优先增加跨重启草稿恢复和明确的“正在停止”提示，避免用户担心内容丢失或重复点击。
2. 图片任务增加取消/后台进度和完成提示，长任务完成时尽量保留用户当前浏览位置。
3. 将 API 错误逐步统一成非阻塞提示，保留原请求重试入口，减少遮挡操作的弹窗。
4. 设置保存进一步按修改字段提交并处理多窗口冲突；当前快速模型选择已改成局部提交。
5. 前端代码高亮依赖较大，可按需加载；需结合冷启动测量再改，避免仅为消除构建警告而重构。
6. 多渠道鉴权应逐步改为请求级配置，减少依赖全局设置临时写入的握手锁。
