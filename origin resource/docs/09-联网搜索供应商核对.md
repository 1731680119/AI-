# 联网搜索供应商核对

核对日期：2026-10-15。范围为当前程序提供的千问、Kimi、智谱/Z.AI、DeepSeek 搜索协议。以下规则是官方文档快照，不能替代当前密钥、地域权限和上游实际响应的验证。

| 供应商 | 官方接口和规则 | 本次处理 |
| --- | --- | --- |
| 千问 | DashScope Generation / 兼容 Responses；策略、文本/多模态端点、快照支持日期依模型而异 | 前后端共用模型能力目录；仅显示支持的策略，切换时自动调整参数；候选型号明确标为未验证 |
| Kimi Basic | `POST /v1/tools/search`；`text_query`、`limit` 1–20、`timeout_seconds` 1–60、`include_content`；返回 `search_results[].text` | 不获取聊天模型；超时限制 60 秒；支持从根地址、完整接口地址及聊天兼容地址构造搜索路径 |
| Kimi Pro | `POST /v1/tools/search_pro`；无 `include_content`；返回 `search_results[].chunks[].text` | 保留用户明确填写的 Pro 地址，不降级 Basic；按 Pro 结构解析正文 |
| 智谱国内 | `POST https://open.bigmodel.cn/api/paas/v4/web_search`；必填 `search_engine`、`search_query`、`search_intent`；查询最多 70 字；支持 `search_std`、`search_pro` 等 | 默认 `search_pro`，发送国内参数；超长查询明确提示，不静默截断 |
| Z.AI 国际 | `POST https://api.z.ai/api/paas/v4/web_search`；引擎仅 `search-prime` | 按域名区分国际站；仅发送 `search_engine`、`search_query`，不沿用国内的可选参数及 70 字限制 |
| DeepSeek 官方 | Responses 支持函数等工具，但会静默忽略内置 `web_search` | 任何协议选项下均拒绝官方搜索，隐藏模型获取及检索测试；聊天模型列表不受影响 |
| Responses 中转 | 上游实现与授权不同 | 保留兼容能力，但必须由接口返回搜索记录及真实来源，只有文字或正文裸 URL 不能通过检测 |

智谱与 Z.AI 均从 `search_result[]` 读取 `link`、`title`、`content`、`publish_date`。Kimi 从 `search_results[]` 读取结果。空结果、无效结果数组、非网页链接、上游错误都不能算检索成功。401/403/429 不切换搜索服务、不自动重复请求。Coding Plan/MCP 与独立 REST 搜索的接口和授权不同，填写该类地址时明确提示更正。

官方域名优先于配置名称识别供应商，显式选择的协议优先于自动识别。更改供应商、模型、API 或策略会清除过时的检测结果。

## 以后调整时的检查点

1. 按供应商、地域、API 类型核对路径、必填字段、参数范围、模型支持及结果结构，不只检查模型名称。
2. 更新 `backend/search_capabilities.json` 的文档链接与核对日期，前后端共用同一规则；未知型号不猜测策略。
3. 用 `backend/tests/test_search.py` 验证真实请求构造和响应解析，覆盖官方错误与无来源结果；运行前端回归及隔离 Electron 检查。
4. 重新编译后端、构建前端、做临时数据目录冒烟，并校验安装包资源与产物一致。
5. 用“检索测试”验证用户实际账号授权。模型清单和模拟测试不能证明密钥能使用付费服务。失败不自动切换供应商或收费服务。

本轮验证：后端搜索 26 项、聊天 API 7 项、前端 23 项、隔离 Electron 10 项通过。使用模拟上游和临时数据目录，未读取用户密钥或调用付费搜索。
