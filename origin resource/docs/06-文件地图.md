# 文件地图

每个文件的作用、关键符号（带行号）、改动注意事项。目的是让你不读源码就能定位。

行号是写文档时的位置，改过代码后会偏移，用符号名搜索更可靠。**改了文件请同步更新本篇对应行。**

## 1. 目录总览

```
origin resource/            源码（唯一可改处）
├─ backend/                 Python FastAPI 后端，约 5400 行
│  ├─ routers/              HTTP 路由层，只做校验和分发
│  └─ *.py                  服务层：数据库、模型调用、工具、文件、日志
├─ frontend/                React + TypeScript + Vite，约 7300 行
│  └─ src/
│     ├─ app/               应用入口与初始化
│     ├─ components/layout/ 侧栏、错误边界
│     ├─ features/          按功能分：chat / images / artifacts / settings / projects / diagnostics
│     ├─ services/api/      HTTP 封装，一个后端模块对应一个文件
│     ├─ store/             Zustand 全局状态与业务编排
│     ├─ styles/            CSS，按功能拆分
│     └─ types/             全局 TypeScript 类型
├─ docs/                    本套文档
├─ tools/ui-check/          GUI 检测（连调试端口驱动真实界面，见 §5）
└─ *.bat                    setup / start / check 便捷脚本

../source/                  桌面打包工程
└─ desktop/                 Electron 主进程、preload、注入脚本
```

## 5. GUI 检测工具

用法见 [`../tools/ui-check/README.md`](../tools/ui-check/README.md)。**不参与打包**，纯开发期工具，
改它不需要升版本、不需要重新出安装包。零 npm 依赖，Node 22+ 直接跑。

原理是连应用自己开的 Chrome DevTools 调试端口（`--remote-debugging-port=9222`），
驱动**真实渲染进程**做点击和输入，再截图 + 跑几何断言 + 与基线做像素 diff。
不用 Puppeteer/Playwright 是因为它们要下自己的浏览器内核，那样测的就不是用户实际跑的那个界面了。

| 文件 | 行数 | 作用 |
| --- | --- | --- |
| `../tools/ui-check/run.mjs` | 359 | 入口与编排：起应用、遍历「分辨率×主题」矩阵、逐场景跑断言截图、出报告。`shutdown()` 必须走优雅退出，硬杀会留下孤儿后端进程和假的「未处理-」诊断文件夹 |
| `../tools/ui-check/cdp.mjs` | 257 | 极简 CDP 客户端。`clickTarget()` 用 `Input.dispatchMouseEvent` 而不是 `el.click()`——后者绕过命中测试，被遮住也能"点到"，而那正是要查的问题 |
| `../tools/ui-check/rules.mjs` | 223 | 几何断言规则，整段注入页面执行。7 条规则，每条对应一个真实踩过的坑（见 05 §5 / CLAUDE.md §5） |
| `../tools/ui-check/scenes.mjs` | 205 | 界面场景定义 + `RESET_STEPS`。**所有场景必须只读**：这套东西对着真实 `user-data/` 跑 |
| `../tools/ui-check/diff.mjs` | 88 | 像素 diff。借页面自己的 Canvas 做，所以不用装 pngjs/pixelmatch |
| `../tools/ui-check/report.mjs` | 134 | 生成自带样式的 HTML 报告 |
| `../tools/ui-check/baseline/`、`report/` | — | 本机产物，已 gitignore。基线**不能跨机器共用**（字体渲染和 DPI 不同会全是假差异） |

抓不到的东西：**Electron 主进程的原生 UI**（窗口菜单、`dialog.showErrorBox`、托盘、
系统通知、NSIS 安装界面）不在渲染进程里，CDP 看不见，只能靠代码审查或系统级截屏。
